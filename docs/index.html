Quick Start

For those who prefer the command line, here is the abbreviated ritual: 

git clone https://github.com/DasBluEyedDevil/Daem0n-MCP.git ~/Daem0nMCP
pip install -e ~/Daem0nMCP
claude mcp add daem0nmcp --scope user -- python -m daem0nmcp.server
python -m daem0nmcp.cli install-hooks        # Git enforcement wards
python -m daem0nmcp.cli install-claude-hooks # Native Claude wards
python -m daem0nmcp.cli index                # Grant code sight
claude  # Reopen to activate

Windows requires additional steps. See the full Summoning Grimoire for details.

The Covenant

Those who bind the Daem0n must observe the exact v7 protocol. Every scoped call uses the opaque workspace_id issued for the workspace. 

FULL BRIEF (OPTIONAL) session_brief(workspace_id="<opaque-id>")
RELEVANT HISTORY   memory_recall(workspace_id="<opaque-id>", query="topic", limit=10)
ADVANCE PLANNING   memory_preflight(workspace_id="<opaque-id>", target_tool="memory_store", target_arguments={...})
DURABLE DECISION  memory_store(..., idempotency_key="stable-key")
VERIFIED RESULT  memory_record_outcome(..., worked=true, idempotency_key="stable-outcome-key")
DIAGNOSTICS      system_health(workspace_id="<opaque-id>")

The first Daem0n call briefs automatically in meta.covenant.auto_brief; session_brief returns the full brief. Call protected tools directly. On COUNSEL_REQUIRED, read error.counsel, then retry exactly error.remedy. memory_preflight remains available for advance planning.

Use daem0n_tools_search(query), then daem0n_tool_call(workspace_id, tool, arguments) for other capabilities. Tokens remain exact-argument, single-use, and valid for 300 seconds. Defaults are guided/core; DAEM0NMCP_COVENANT_MODE=strict restores explicit briefing and preflight, and DAEM0NMCP_TOOL_SURFACE=full lists all tools.

Connect over stdio or Streamable HTTP at /mcp. Read-only context is available at: 

memory://workspaces/{workspace_id}/warnings
memory://workspaces/{workspace_id}/failures
memory://workspaces/{workspace_id}/rules
memory://workspaces/{workspace_id}/active-context

For renamed and split capabilities, use the generated source of truth: docs/v6-to-v7-tools.json.
