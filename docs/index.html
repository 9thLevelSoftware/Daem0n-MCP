The Sacred Powers

Event-Sourced Ledger

Append-only, hash-chained memory_events in SQLite project convergently into FTS5, dense Qdrant, graph, temporal, procedure, and outcome indexes—verified offline via verify-v7 and upgraded atomically via migrate-v7 with retained-generation rollback.

Portable Workspace Identity

Memories travel when folders are moved, renamed, or re-cloned via .daem0nmcp/workspace-id and active SQLite identity persistence. Duplicate or mismatched roots fail closed (WORKSPACE_IDENTITY_DUPLICATE / WORKSPACE_RELOCATED), with clean workspace-id --new forks and --adopt recovery.

Multi-Channel Retrieval

SQLite FTS5 lexical search (with optional content-tiering) runs in parallel alongside dense Qdrant vectors, graph, temporal, procedure, and outcome channels—returning rank-ordered results with bounded category diversity and strict [E1] citation-manifest parity.

Provenance & Utility Ranking

Schema 33 tracks informed_by causal lineage and verification-weighted outcomes. Shadow-first utility ranking elevates proven memories among near-equal matches without overriding stronger semantic relevance.

Code-Binding Validity

Tree-sitter indexes multi-language symbols and TypeScript relationships. Memories bind to workspace-relative paths and AST-fingerprinted symbols (including Python/TS decorators and Rust attributes), re-reading bounded source bytes on recall to flag needs_revalidation changes.

Deep Sight & Late Interaction

nomic-ai/modernbert-embed-base (256-dim Matryoshka, asymmetric query/document prefixes, pooled ONNX runtime on Python 3.11+) pairs with the optional late-interaction profile for lazy ColBERT/MaxSim reranking.

Core + Gateway Surface

Nine core tools listed by default front all 77 registered typed v7 tools via daem0n_tools_search and daem0n_tool_call (or expose all 77 with DAEM0NMCP_TOOL_SURFACE=full), with protocol instructions delivered during MCP initialize.

Guided Covenant & Remedies

Guided sessions auto-brief on the first memory call and admit benign writes with inline counsel. Risky or destructive calls return COUNSEL_REQUIRED with error.counsel and an exact, single-use 300s error.remedy.

Untrusted Content Ward

Scanned code TODOs and SSRF-pinned URL ingestions are quarantined as withheld_untrusted—excluded from session briefs, counsel triggers, and read-only resources so external text remains data, never instructions, while staying searchable in memory_recall.

Native Wards & Edit Gate

Read-only hooks whisper file-recall hints, active rules (pre_bash over read-only SQLite), and replay-safe outcome reminders without mutating storage—while opt-in enforce mode gates declared native file edits with edit_preflight receipts.

Knowledge Graph & Leiden Communities

Quick Start

For those who prefer the command line, run from the trusted ~/Daem0n-MCP checkout using its dedicated virtual environment: 

git clone https://github.com/9thLevelSoftware/Daem0n-MCP.git ~/Daem0n-MCP
cd ~/Daem0n-MCP && python3.12 -m venv .venv      # Windows: py -3.12 -m venv .venv
.venv/bin/python -m pip install -e '.[local,graph,apps,models-local]'
.venv/bin/python -m daem0nmcp.cli --project-path "<PROJECT>" --json workspace-id
.venv/bin/python -m daem0nmcp.cli --project-path "<PROJECT>" install-client codex --client-version "<VER>"  # or agy|opencode|omp|pi
claude mcp add daem0nmcp --scope project --transport stdio -e "DAEM0NMCP_PROJECT_ROOT=<PROJECT_ROOT>" -- "<VENV_PYTHON>" -c "import sys; sys.path = [p for p in sys.path if p]; import runpy; runpy.run_module('daem0nmcp.server', run_name='__main__', alter_sys=True)"
.venv/bin/python -m daem0nmcp.cli --project-path "<PROJECT>" install-claude-hooks   # Native Claude wards
.venv/bin/python -m daem0nmcp.cli --project-path "<PROJECT>" install-hooks          # Git enforcement wards

stdio is the default across Windows (.venv\Scripts\python.exe), macOS, and Linux. Existing v6 or older v7 stores upgrade safely offline via migrate-v7 --apply and validate via verify-v7. See Summon_Daem0n.md for the complete ritual.

The Covenant

Those who bind the Daem0n must observe the exact v7 protocol. Every scoped call uses the opaque workspace_id issued for the workspace. 

FULL BRIEF (OPTIONAL) session_brief(workspace_id="<opaque-id>")
RELEVANT HISTORY      memory_recall(workspace_id="<opaque-id>", query="topic", limit=10)
ADVANCE PLANNING      memory_preflight(workspace_id="<opaque-id>", target_tool="memory_store", target_arguments={...})
DURABLE DECISION      memory_store(..., idempotency_key="stable-key")
VERIFIED RESULT       memory_record_outcome(..., worked=true, idempotency_key="stable-outcome-key")
NATIVE EDIT GATE      edit_preflight(workspace_id="<opaque-id>", ...)
DISCOVER & INVOKE     daem0n_tools_search(query) -> daem0n_tool_call(workspace_id, tool, arguments)
DIAGNOSTICS           system_health(workspace_id="<opaque-id>")

The server publishes active protocol instructions during MCP initialize. The first gated call briefs automatically in meta.covenant.auto_brief; session_brief returns the full brief. Call protected tools directly: benign writes proceed with inline counsel, while risky or destructive calls return an isError: true envelope with COUNSEL_REQUIRED, error.counsel, and an exact retryable error.remedy. memory_preflight remains available for advance planning.

Use daem0n_tools_search(query) and daem0n_tool_call(workspace_id, tool, arguments) to invoke any of the 77 registered capabilities. Tokens remain exact-argument, single-use, and valid for 300 seconds. Defaults are guided/core; DAEM0NMCP_COVENANT_MODE=strict restores explicit briefing and preflight, and DAEM0NMCP_TOOL_SURFACE=full lists all 77 tools.

Connect over stdio or Streamable HTTP at /mcp (remote or proxied HTTP requires configured FASTMCP_SERVER_AUTH and DAEM0NMCP_WORKSPACE_ACCESS_FILE). Read-only context and visual dashboard portals live at: 

memory://workspaces/{workspace_id}/warnings
memory://workspaces/{workspace_id}/failures
memory://workspaces/{workspace_id}/rules
memory://workspaces/{workspace_id}/active-context
UI PORTALS  ui://daem0n/{briefing|community|covenant|graph|search|test}

For renamed and split capabilities, use the generated source of truth: docs/v6-to-v7-tools.json.
